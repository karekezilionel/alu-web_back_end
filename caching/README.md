# Caching

This directory contains caching system implementations for the ALU
Web Backend curriculum.

## Files

- `base_caching.py` — Base class for all caching systems
- `0-basic_cache.py` — BasicCache: unlimited dictionary cache
- `1-fifo_cache.py` — FIFOCache: First-In-First-Out cache (MAX_ITEMS = 4)
- `2-lifo_cache.py` — LIFOCache: Last-In-First-Out cache (MAX_ITEMS = 4)
